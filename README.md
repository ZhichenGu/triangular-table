# 潮汐之席 · The Tidal Table

可运行的 Three.js 单页艺术展示网站：暗色空间、中央镂空三角餐桌、象牙白垂落桌布、三套餐盘餐具与海洋形态作品。

## 本地运行

需要 Node.js 22.12+（或 Vite 7 支持的版本）。

```sh
npm ci
npm run dev -- --port 5173
```

打开终端显示的本地 URL，默认 `http://127.0.0.1:5173/`。

```sh
npm test
npm run build
npm run preview
```

构建文件在 `dist/`，可部署到静态网站托管。本项目当前仅完成本地预览及 GitHub 代码同步，没有线上部署。

## 交互

- 首屏只显示纯黑背景、尖角朝前的低机位三角餐桌和 A / D 方向控件。
- A / D 或下方按钮每次旋转 120°，同方向三次归位。快速独立输入按顺序执行。
- 鼠标悬停餐盘或物件，中央打开餐盘查看窗口；触屏或键盘可点选餐盘。
- 窗口内拖动旋转物件，滚轮或 ＋ / − 缩放至 75%–180%，↺ 复位。缩放较大时自动调整取景以保持完整。
- 查看窗口保持打开，方便鼠标从餐桌移入窗口；点击 ×、外部或按 Esc 关闭。关闭后同一餐盘不会立即重开，移开鼠标后可重新悬停。
- 窗口的查看状态独立于桌面陈列，三个物件分别保留缩放和角度。按 A / D 会关闭窗口并转动餐桌。
- 减少动态效果偏好启用时，餐桌按步立即切换。

## 替换真实模型

当前三个物件为根据原始二维图创作的程序化三维概念近似，非精确复刻；未提供的背面与侧面为推测。原始图保留在 `references/objects.jpg`。

把 `.glb` 放入 `public/models/`，修改 `src/objects.js` 的 `OBJECTS` 配置：

```js
{ model: '/models/wave.glb', scale: 1, rotation: 0, height: 0, ... }
```

`rotation` 单位为弧度。模型先自动归一到约 1.55 单位宽度、居中、底部对齐，再应用配置。加载成功后替换代理，保留现有命中、缩放和旋转；加载失败保留代理并报告错误。模型底部应位于餐盘上方，按模型需要调整 `height`。

## 验证

六项 Node 自动检查覆盖：A×3 / D×3 归位、反向与快速混合输入、连续角度单调性、减少动态效果、缩放边界、三套餐盘及三种物件的几何有效性和底部对齐。

实际浏览器检查覆盖桌面与 390×844 窄屏、连续按键归位、独立缩放、拖动与滚轮、复位、方向按钮和原稿说明。详情见 `VERIFICATION.md`。
